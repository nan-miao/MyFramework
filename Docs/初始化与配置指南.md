# 初始化与配置指南

MyFramework 各管理器的初始化顺序、场景搭建步骤和宏配置说明。

---

## 场景初始化

### 推荐场景结构

创建一个 `Bootstrap` 或 `Startup` 场景作为游戏入口，挂载所有必要的 Manager：

```
Startup Scene Hierarchy:
├── --- Managers --- (空 GameObject)
│   ├── MonoManager         (需手动挂载 SingletonMono)
│   ├── LogSystem           (自动创建 SingletonAutoMono)
│   ├── PoolManager         (自动创建 SingletonAutoMono)
│   ├── TimerManager        (自动创建 SingletonAutoMono)
│   ├── InputManager        (自动创建 SingletonAutoMono)
│   ├── AStarManager        (自动创建 SingletonAutoMono)
│   └── AStarMonoManager    (自动创建 SingletonAutoMono)
├── --- Save ---
│   └── SaveManager         (需手动挂载 SingletonMono)
├── --- Scene Objects ---
│   ├── CameraManager       (需手动挂载 SingletonMono)
│   └── ...游戏场景对象
```

### Manager 类型速查

| Manager | 类型 | 创建方式 | 自动跨场景 |
|---|---|---|---|
| MonoManager | `SingletonMono` | 手动挂载 | 可选 (global) |
| LogSystem | `SingletonAutoMono` | 首次访问自动创建 | 是 |
| PoolManager | `SingletonAutoMono` | 首次访问自动创建 | 是 |
| TimerManager | `SingletonAutoMono` | 首次访问自动创建 | 是 |
| InputManager (新版) | `SingletonAutoMono` | 首次访问自动创建 | 是 |
| AStarManager | `SingletonAutoMono` | 首次访问自动创建 | 是 |
| AStarMonoManager | `SingletonAutoMono` | 首次访问自动创建 | 是 |
| AStarPathHelper | `SingletonAutoMono` | 首次访问自动创建 | 是 |
| PhysicsSimulator2D | `SingletonAutoMono` | 首次访问自动创建 | 是 |
| SaveManager | `SingletonMono` | 手动挂载 | 否 (global=false) |
| CameraManager | `SingletonMono` | 手动挂载 | 否 (global=false) |
| AddressablesManager | `BaseManager` | 首次访问自动创建 | 天然全局 |
| ResManager | `BaseManager` | 首次访问自动创建 | 天然全局 |
| EditorResManager | `BaseManager` | 首次访问自动创建 | 天然全局 |
| SceneLoader | `BaseManager` | 首次访问自动创建 | 天然全局 |
| InputMgr (旧版) | `BaseManager` | 首次访问自动创建 | 天然全局 |

## 初始化顺序

```
MonoManager (最先 — 需在 Start 前可用)
    │
    ├── LogSystem ── 日志系统（依赖 OPEN_LOG 宏）
    ├── PoolManager ── 对象池（自动创建 4 个默认池）
    │       └── TimerManager ── 依赖 PoolManager (数据池) + MonoManager (协程)
    ├── InputManager ── 输入系统（加载 Addressables 中的 GameInput）
    ├── AStarManager ── 寻路调度（依赖 MonoManager, order=0）
    ├── AStarMonoManager ── 移动驱动（依赖 MonoManager, order=1）
    └── SaveManager ── 存档（场景启动时自动查找 ISaveData）
```

## 宏与编译配置

### OPEN_LOG（日志编译剔除）

通过编辑器菜单 `Tools → 打开日志系统` 控制：

| 宏状态 | 效果 | 适用阶段 |
|---|---|---|
| 定义 `OPEN_LOG` | 日志代码编译且生效 | 开发/测试 |
| 移除 `OPEN_LOG` | 所有 `DebugLogger` 调用在编译时完全剔除 | 发布 |

> 注意：移除 `OPEN_LOG` 后 `LogSystem.Awake()` 会自动执行 `Debug.unityLogger.logEnabled = false`。

## ScriptableObject 配置

### LogConfig
路径: `Assets → Create → Data → Debuger → LogConfig`

### SaveConfig
路径: `Assets → Create → Data → SO → GlobalConfig → SaveConfig`
配置: fileName, saveType (Global/Player), useEncryption, encryptionKey

## InputSystem 配置

1. 安装 `com.unity.inputsystem` 包
2. 创建 InputActionAsset（如 `GameInput.inputactions`）
3. 配置 ActionMap（如 GamePlay）和 Action（如 LeftMouseClick）
4. 在 `InputActionType` 和 `InputActionMapType` 枚举中注册（名称需一致）
5. 将 Asset 标记为 Addressables，标签命名为 `"GameInput"`
6. InputManager 启动时通过 Addressables 自动加载

---

## Addressables 资源配置

使用 Addressables 前需先执行初始化：

1. 安装 Addressables 包
2. 将资源标记为 Addressable（设置 key）
3. 构建 Addressables 内容（`Window → Asset Management → Addressables → Build`）

---

## PoolManager 默认池

`PoolManager.OnStart()` 自动创建的 4 个 AutoRelease 池：

| PoolType | 释放时间 | 建议用途 |
|---|---|---|
| Effect | 400s | 战斗特效、粒子 |
| Enemy | 600s | 敌人、怪物 |
| Bullet | 200s | 子弹、弹幕 |
| DropItem | 600s | 掉落物品 |

可根据需要调整时间或添加新池。

## 场景切换

```csharp
// 加载主场景（确保 Startup 场景先加载）
SceneLoader.Instance.LoadSceneAsync("MainScene", LoadSceneMode.Single, ...);

// Addressables 场景会自动处理依赖的资源引用计数
```
