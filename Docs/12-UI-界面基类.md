# UI 界面基类

BasePanel 提供 UI 控件自动绑定和事件分发的面板基类，通过反射查找子控件并自动注册事件监听。同时提供 `ButtonHandler` 和 `MouseInteraction` 两个交互辅助组件。

**命名空间**: `MyFramework.UI`

---

## BasePanel 核心机制

**Awake 阶段自动执行**：
1. 遍历所有子 GameObject
2. 按优先级查找控件: Button → Toggle → Slider → InputField → ScrollRect → Dropdown → Text → TextMeshProUGUI → Image
3. 过滤默认控件名（Image, Text(TMP), RawImage, Background, Checkmark, Label 等）
4. 将非默认名的控件存入 `controlDic` 字典
5. 自动为 Button/Toggle/Slider 添加事件监听

---

## 使用示例

```csharp
using UnityEngine.UI;
using TMPro;
using MyFramework.UI;

public class MainPanel : BasePanel
{
    // 子控件按命名约定绑定
    // "BtnStart", "SliderVolume", "TglMusic", "TxtTitle"

    public override void ShowMe() => gameObject.SetActive(true);
    public override void HideMe() => gameObject.SetActive(false);

    // 按钮点击（自动绑定）
    protected override void ClickBtn(string btnName)
    {
        switch (btnName)
        {
            case "BtnStart":
                Debug.Log("点击开始");
                break;
            case "BtnSettings":
                Debug.Log("打开设置");
                break;
        }
    }

    // 滑块值变化（自动绑定）
    protected override void SliderValueChange(string sliderName, float value)
    {
        if (sliderName == "SliderVolume")
            AudioListener.volume = value;
    }

    // Toggle 值变化（自动绑定）
    protected override void ToggleValueChange(string toggleName, bool value)
    {
        if (toggleName == "TglMusic")
        {
            // 背景音乐开关
        }
    }

    // 手动获取控件
    public void UpdateUI()
    {
        var title = GetControl<TextMeshProUGUI>("TxtTitle");
        if (title != null) title.text = "主菜单";

        var startBtn = GetControl<Button>("BtnStart");
        startBtn.interactable = true;
    }
}
```

## controlDic 字典

```csharp
// 内置字典: Dictionary<string, UIBehaviour>
protected Dictionary<string, UIBehaviour> controlDic;

// 获取控件
public T GetControl<T>(string name) where T : UIBehaviour
{
    if (controlDic.ContainsKey(name))
        return controlDic[name] as T;
    return null;
}
```

## 默认控件名过滤列表

以下名称的 GameObject 不会被绑定（通常是 UI 模板内置子对象）：

```
Image, Text (TMP), RawImage, Background, Checkmark, Label,
Text (Legacy), Arrow, Placeholder, Fill, Handle, Viewport,
Scrollbar Horizontal, Scrollbar Vertical
```

## ButtonHandler

按钮交互辅助组件，实现 `IPointerEnterHandler` / `IPointerExitHandler`，提供 `MouseEnter` 和 `MouseExit` 事件：

```csharp
public class ButtonHandler : MonoBehaviour, IPointerEnterHandler, IPointerExitHandler
{
    public Button button;           // 缓存 Button 引用
    public Action MouseEnter;       // 鼠标进入事件
    public Action MouseExit;        // 鼠标离开事件
}
```

## MouseInteraction

通用的鼠标交互组件（不含 Button 引用）：

```csharp
public class MouseInteraction : MonoBehaviour, IPointerEnterHandler, IPointerExitHandler
{
    public Action MouseEnter;
    public Action MouseExit;
}
```

## 注意事项

- **命名即约定**：GameObject 名称是绑定 key，同一面板内不可重名。
- **优先级策略**：同一 GameObject 上同时有 Button 和 Image，Button 优先绑定（Button 在 Image 前面查找）。
- **Text 类型双支持**：同时支持 `Text`（旧 UI）和 `TextMeshProUGUI`（TMP）。
- **虚方法按需重写**：`ShowMe()`、`HideMe()`、`ClickBtn()`、`SliderValueChange()`、`ToggleValueChange()`。
- **手动获取**：`GetControl<T>()` 找不到时输出 Error 日志。
- **AutoRelease 交互**：`ShowMe()`/`HideMe()` 通常搭配 PoolManager 的 AutoRelease 池使用。
